# Java Servlet Portfolio

A focused portfolio of my hands-on work with **Java Servlets**, covering request handling, redirect/forward flow control, and a complete registration workflow.

## Featured Projects

| Project | Focus Area | What it demonstrates | Repository |
|---|---|---|---|
| WebApp4_ServletGetPost | HTTP method handling | `doGet()` and `doPost()`, parameter capture, form submission flow | [View Repo](https://github.com/VindhyaVankayala/WebApp4_ServletGetPost) |
| WebApp5_ServletRedirect | Navigation control | Redirect-based flow using `sendRedirect()`, response lifecycle understanding | [View Repo](https://github.com/VindhyaVankayala/WebApp5_ServletRedirect) |
| WebApp6_ServletReqDispatch | Server-side forwarding | `RequestDispatcher` with `forward()`/`include()`, request attribute passing | [View Repo](https://github.com/VindhyaVankayala/WebApp6_ServletReqDispatch) |

## Servlet Skills Demonstrated

- Java Servlet lifecycle understanding
- Handling client requests with `HttpServlet`
- `doGet()` / `doPost()` implementation
- Reading request parameters and generating responses
- Navigation patterns:
  - Client-side redirect (`sendRedirect`)
  - Server-side forward/include (`RequestDispatcher`)
- Building multi-step web flow from form input to result pages
